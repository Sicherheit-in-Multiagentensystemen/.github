# Sicherheit in Multiagentensystemen

**多智能体系统安全 · Security in Multi-Agent Systems**

本组织用于研究多智能体系统的安全问题：智能体间提示注入与传播、共享记忆污染、身份与权限委派、协作鲁棒性、资源耗尽，以及防御机制的组合安全与评测。

当前以 LLM 多智能体系统为重点，结合传统 MAS、MARL 和分布式容错基础。资料正文以中文为主，保留英文论文标题、完整引用和原始来源。

## 资料维护原则

追溯原始来源，区分预印本与已核验发表信息；明确区分论文作者报告、整理者解读与独立复现结果。新增文献时同时记录系统假设、攻击者能力、评测条件和局限。
